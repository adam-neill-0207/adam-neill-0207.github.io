# Portfolio Website

This portfolio website showcases my work in sports broadcast graphic design. It is designed with a modern and stylish layout that avoids scrolling on PC, providing an engaging user experience.

## Project Structure

```
portfolio-website
├── src
│   ├── css
│   │   ├── style.css
│   │   └── normalize.css
│   ├── js
│   │   └── main.js
│   └── pages
│       ├── projects.html
│       ├── contact.html
│       └── about.html
├── assets
│   └── fonts
├── index.html
└── README.md
```

## Features

- **Responsive Design**: The website is designed to be visually appealing on all devices.
- **Interactive Elements**: JavaScript is used to enhance user interaction and dynamic content loading.
- **Sections**: The website includes sections for project links, personal information, contact details, and a brief introduction.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open `index.html` in your web browser to view the portfolio.
3. Customize the content in the `src/pages` directory to add your projects and personal information.
